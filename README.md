# FrameDash

Dashboard and art display for the Lenovo Smart Frame (CD-3L501F, Android 10, landscape).
Forked from FridgeDash; the two apps are now independent.

- **Dashboard:** clock, weather, today's daily brief (Notion or GitHub file), shortcut row.
- **Art mode:** paintings (Art Institute of Chicago, The Met) and Google Photos shared albums when idle.
- **Gestures & buttons:** teach the frame's buttons and gesture sensor what to do.

Every push to `main` builds a signed release. Install or update from
`https://github.com/armadocs/Lenovo_Frame/releases/latest/download/framedash.apk`
or Settings → Updates on the frame.
